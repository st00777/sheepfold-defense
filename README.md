# 羊圈守夜

聖經主題的格子塔防小遊戲，手機瀏覽器直接玩。James 的個人興趣作，與「靈修冒險」各自獨立。

- 玩家身分：受託守夜的無名牧人。聖經人物只在關卡開頭與結尾說話，不是可操控的單位；遇到耶穌或神親自說話的經文用「經文卡」引述。
- 單位與敵人全部原創，都是人、動物、器具、地形；不把神蹟做成按鈕。關卡取材自經文裡牧人真的守過的夜（雅各、大衛、摩西、阿摩司、基甸……）。
- 原生 JavaScript，無建置步驟。

## 怎麼玩
點一張卡，再點草地放下單位。狼從右邊來，走到最左邊就失敗；撐過全部波次就天亮。
哪一排右邊出現 🐾 腳印，下一隻狼就從那排來；腳印換成別的圖示，表示來的不是普通狼。
每關開場可選三種夜：寧靜夜、起風夜（狼更多更壯）、暴風夜（糧來得慢，多放幾個牧人）。守過一夜就開下一夜，進度與最高紀錄只存在自己手機裡。

## 檔案
- `index.html` 流程與操作：關卡、卡片列、暫停、結算、存檔、音效、看門的走道與外框
- `render.js` 棋盤畫面：用 PixiJS 畫在 canvas 上（2026-10-23 起，原本是 DOM 格子）。單位、敵人、投射物、效果、無月夜黑暗與油燈亮帶、天色、雨與閃電都在這裡；只讀引擎狀態、聽引擎事件
- `lib/pixi.min.js` PixiJS 8.9.2（MIT，授權在 `lib/LICENSE-pixi.txt`）；放在 repo 裡鎖版本，不吃 CDN
- `data.js` 單位／敵人／狀態／難度／關卡資料表（加內容只改這裡）
- `engine.js` 純邏輯引擎，無 DOM，Node 可跑
- `save.js` 存檔（2026-10-29 期 0）：整支手機的紀錄放在一份 `sheepfold-save`（v4，有版本欄與遷移鏈）——進度、星、每關檢查點、隊伍、看過的介紹、教學、設定。純邏輯無 DOM，測試在 `sim/save.test.js`。舊的十幾個散放 key 第一次開新版自動搬進來、搬成功才刪；主檔讀不出來先用前一次開頁抄的 `-bak` 接回、再不行才從頭，原文留在 `-broken`，首頁說一聲不靜默
- `sound.js` 音效：Web Audio 現場合成，沒有音檔；頂欄與開場頁 🔊 一鍵靜音，暫停層有音效／蟲鳴／音量三檔（設定住在存檔 `prefs.sound`，由 `Sound.attach` 接）
- 頂欄 ⏩ 二倍速（存檔 `prefs.speed`，加速時裝飾動畫關掉只留資訊）；暫停層「大字」把整頁放大 1.18 倍（`prefs.big`）。2026-10-20 多視角審查加的
- 星級：每夜三顆（守過／零損失＝沒失羊／看門的都在——這個難度開局有幾位就要幾位都在），跨局累積、不解鎖任何東西；規則與邊界見 `docs/chapter-expansion-design-2026-10-18.md` §13。
- `sim/simulate.js` 勝率模擬：`node sim/simulate.js [關|all] [calm|windy|storm|all] [局數] [good|basic|line|thorns|multi|compare]`（輸出含「最近幾格」＝敵人最靠近羊圈到哪，越小越驚險）。`line`＝射手守線、`thorns`＝荊棘續航、`multi`＝多排調度三套固定打法；`compare` 用同一批種子把四套各跑一遍印成一張表，並數「只有某一套贏」的局數（2026-10-22）；`SIM_MODS='{"units":["shepherd","slinger","wall"],"startFood":300,"gates":2,"waves":3}'` 套修飾詞跑（期 1，2026-10-29：`units` 白名單、`startFood` 開局糧、`gates` 看門數 0–5 或排號陣列、`waves` 只打前幾波、`conveyor` 送卡開關或設定、`oneBudget` 一筆糧開關；程式裡是 `Engine.create(id, diff, rng, mods)`，`Engine.checkMods(id, mods)` 先驗，檢查點帶著修飾詞、不同組不能接）；`node --test sim/*.test.js` 跑引擎測試
- `docs/roster.md` 單位／敵人／關卡定案；`docs/level-design.md` 每關新鮮感與教學順序；`docs/chapter-2-design.md` 第二章完整規格

## 兩章各十夜（2026-10-18 起）
第一章「守夜」第 1-10 夜、第二章「另外的羊」第 11-20 夜。畫面上的「第 N 夜」是順序，存檔綁的是關卡 id（中途插新夜老玩家紀錄不掉；解鎖＝本夜／前一夜／任一後夜守過即開）。門口有**看門的**（約 10:3）：第一隻走到門口的地面敵人被他擋下、整排趕出場，用過就沒了，那排再漏就輸；飛的不經過門。**2026-10-20 起依難度**：寧靜夜每排一位、起風夜中間三排、暴風夜第 2、4 排（`DIFFS[難度].gates`，關卡 `gates: false` 一律沒有）。迷羊走來前 3 秒會先印 🐑 腳印。關卡表見 `docs/roster.md`，補夜設計與拍板見 `docs/chapter-expansion-design-2026-10-18.md`。

## 封面與分享預覽（2026-10-26）
`img/cover.jpg`（1200×630）是臉書／LINE 分享時抓的預覽圖，`img/icon-512.png`／`icon-180.png` 是書籤與加到主畫面的圖示，都從同一張封面來。封面的做法：先用遊戲裡的 Fluent 圖示排一張草稿（構圖照植物大戰殭屍：好人左、壞人右、標題左上、月亮右上），再請 ChatGPT 照草稿畫成插畫；原圖 1730×909 存在 James 的 ~/glc-work。分享預覽用的 og 標籤在 `index.html` 的 head；換圖之後臉書會快取舊圖，要到 developers.facebook.com/tools/debug 按「重新抓取」。

## 第三章「諸山間」（2026-10-24 起，10/26 上正式版）
第 21-30 夜，一條環境規則＝**山坡**（`level.hill: 4`）：右邊三格是斜坡，羊圈在山上、敵人從山下爬上來。高地的直射（石子、箭、機弦）飛到坡緣就從斜坡上敵人頭頂飛過去打不到；拋射（投石機、拋石手）與飛的不受影響；斜坡三格的單位跟敵人同一斜面一切照舊；斜坡上的地面敵人走 0.85 倍（野牛例外）。主題＝**高低差**：第一次讓「射手放後面、牆放最前」這個反射動作出錯。五張新卡＋一個升級：拋石手（拋最前面那隻）、石堆（只能堆在斜坡，咬垮或點一下推倒就滾石）、陷坑（困住第一隻踩進來的 4 秒／頭目 2.5 秒）、水袋（九格回滿血）、投石機升「巧匠的機器」。三種新敵人：強盜（站在斜坡上丟石頭）、大鷹（飛高打不到，守望樓那排飛不高；抓羊飛低，打下來羊落地走回圈、名額不加不給糧）、野牛（頭目，推不動、狗不理、只有陷坑困得住）。第 25 夜「亞比該的禮物」是**一筆糧**：沒有牧人、糧不滴，開局 1600（起風 ×1.25、暴風 ×1.4）用完就沒了。規格與施工紀錄見 `docs/chapter-3-design.md`。

## 第二章「另外的羊」（2026-10-17 起）
一條環境規則＝**無月夜**：每夜第二波起看不到腳印預告，油燈照到的三排例外。主題＝**跨路徑**：敵人會換排（豺狼碰到牆繞路、豹每 7 秒換排、夜鴞在三排之間飄），我方工具跨排（牧人杖把敵人趕到隔壁排、投石隊同時打三排、巡夜人在三排之間巡邏並優先靠向受威脅的排、銀號五排一起退）。迦密的夜、走迷的羊、分開的羊群、合成一群四夜有**迷羊**（中立）從右邊走進來，走到最左邊或本排／上下鄰排抱羊羔牧人所在的欄位就回圈（羊數 +1、糧 +25），被狼叼出場算失落一隻。第 11 夜「拉班的工價」是**送卡模式**：沒有糧也沒有牧人，卡片定時送到手上，送來什麼用什麼；拆掉的單位退回手上。
音效也從第二章進場：看不到腳印就要靠聽——夜鴞出生時叫、豹出生與蹲伏時低吼、野豬撞牆有聲。

## 設定頁、存檔碼、更新公告、匿名統計（2026-10-29）
首頁左上 ⚙️ 進設定頁。**存檔碼**：「匯出」把整份存檔變成一串 `SF4.…` 的純 ASCII 字串（最後 8 碼是校驗，少字改字會被擋），複製後貼到 LINE 或備忘錄留著；換手機時「匯入」貼回來，會先顯示那份守過幾夜、幾份檢查點、最後更新日期，再按一次確定才整份蓋掉並重新載入。**更新公告與更新紀錄**：歷次玩家看得到的改動記在 index.html 的 `CHANGELOG`（最新在前，`APP_VERSION`／`UPDATE_NOTES` 取第一筆；純整理程式、文件、測試的進版不列也不改版本號）。版本變了，已經有存檔的玩家開頁彈一次最新那筆，看過記在存檔 `announced`；全新玩家不彈。設定頁「歷次更新紀錄」可翻全部版本。**匿名統計**：gtag 直接接 GA4（跟靈修冒險共用資源 `G-HZ3EGYB8BB`，每個事件帶 `game: sheepfold`，要換自己的資料串流只改 `GA_ID` 一行），只記四種事件——`night_start`、`night_end`（夜數／難度／結果／波／星／失羊／秒數）、`card_used`（每夜每張卡放了幾次）、`open_codex`；使用者屬性 `player_kind` 第一次接統計時有通關紀錄＝returning、沒有＝new。不記姓名帳號；設定頁可關；`?dev`、本機 file: 開的頁面、開過開發者面板的那局不送。

## 暫停與檢查點
上方 ⏸ 暫停，切到背景（`visibilitychange`、`pagehide`）也會自動暫停（棋盤上的動畫也一起停）。每清完一波自動存檢查點（場上單位與糧、羊的損失、見過的敵人、修補冷卻，不存狼），重開遊戲進同一關會問「繼續上次」，從下一波開頭接；守完、輸了、重新開始**同一關**會清掉；中途回關卡或去玩別關都會保留（每關各一份在存檔 `checkpoints` 裡，互不覆蓋）。開過開發者面板的那一局不存。檢查點壞掉（被改過、版本變了）會擋下並在開場頁說明，從頭守。

## 第 1 關教學
第一次玩第 1 關會手把手三步：放牧人、等糧放投石手、放石牆，做完狼才來；可按「我會了，跳過教學」。只教一次，網址加 `?tut` 可重看。

## 再點一下升級
荊棘第 7 夜（提哥亞）起放下後再點一下花 50 糧撒蠍子（原本的蠍窩併進來了），踩入的敵人中毒，持續有效（同一隻只中一次）。10/17 James 拍板：蠍子跟其他單位一樣是持續性的，原本的 8 次是獨立陷阱時代留下的。
纏裹的牧人第 10 夜（最後一夜）再點一下花 50 糧膏油，回血範圍從周圍八格擴大到 5×5、每秒 8 變 12；多隻相鄰會疊加；獅子咆哮嚇不停它。

## 鏟子
卡片列最後一張固定是鏟子，不佔點兵名額。點鏟子再點一個單位就拆掉，退一半糧（老牧人連升級的糧一起算一半）。

## 隊伍與圖鑑
圖鑑三個頁籤（出處一律展開成書卷全名，例如「阿摩司書 3:8」；敵方也有出處）：我方（數字行固定順序：血量→攻擊或產出→範圍→特殊規則，一次性單位寫「沒有血量」）、敵方（血量、傷害、速度之外，嚎叫／狂暴／咆哮／閃避／翻牆／偷羊／鑽地／飛行各帶數字）、效果（穿透、濺射、燃燒、中毒、減速、暈眩、嚇退、咬住、嚎叫、咆哮、狂暴、厚皮十二個名詞各一句）。所有數字從 data.js 帶，改數值不用改文案。對局中按 ⏸ 暫停，暫停畫面有「圖鑑」，只列這一夜同行的卡，看完回暫停。（2026-10-17 James：單位說明太含糊、效果名詞沒定義）

第 4 關起卡超過 8 張，開始前先選 8 張上場（畫面叫「隊伍」，程式裡叫點兵）（牧人與新卡預設帶，名單存在這支手機）。關卡選單的「圖鑑」列已開放的單位與遇過的敵人，點一個看說明、數字與經文出處。

每一夜的卡是固定的（第 1 關只有牧人、投石手、石牆），後面解鎖的夥伴**不會帶回前面的關卡**。玩家手上的卡比這一夜多時，開場頁「今晚上場」後面會說明這是限制；從開場頁開圖鑑，這一夜不同行的卡會暗掉，點開也有說明。

## 開發者模式
網址加 `?all` 解鎖全部關卡；加 `?dev`（或遊戲中**長按**左上角「糧」1.5 秒；2026-10-20 前是連點五下，小孩手滑就會開）打開開發者列：速度 1×／2×／4×／8×、暫停、+500 糧、全卡（這一局所有卡都能用）、下一波、清場、「放敵人」選一種後點任一格就放一隻。調數值的流程：改 `data.js` → `node sim/simulate.js` 看勝率 → 開發者模式實際放敵人看手感。
