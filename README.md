# 羊圈守夜

聖經主題的格子塔防小遊戲，手機瀏覽器直接玩。James 的個人興趣作，與「靈修冒險」各自獨立。

- 玩家身分：受託守夜的無名牧人。聖經人物只在關卡開頭與結尾說話，不是可操控的單位。
- 單位與敵人全部原創；關卡取材自經文場景（第一關：雅各替拉班看守羊群，創世記 31 章）。
- 單一 `index.html`，原生 JavaScript，無建置步驟。

## 怎麼玩
點一張卡，再點草地放下單位。狼從右邊來，走到最左邊就失敗；撐過三波就天亮。
第一波狼只走中間三排，之後才會從兩側繞過來；哪一排右邊出現 🐾 腳印，下一隻狼就從那排來。
開場可選三種夜：寧靜夜（狼少）、起風夜（狼更多更壯）、暴風夜（糧來得慢、狼又多又壯）。最高紀錄三檔各記各的，只存在自己手機裡。
