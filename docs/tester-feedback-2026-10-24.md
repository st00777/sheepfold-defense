# 10/24 測試者回饋問卷（羊圈守夜 第一章＋第二章）

> 用途：10/24 前後收核心玩家回饋，拿來決定第二章數值、抱羊羔的牧人定位、第三章走向。
> 用法：下面「LINE 貼文版」整段複製貼到群組或私訊；回來的答案照「整理表」填，一人一列。

## LINE 貼文版（直接複製）

謝謝你陪我守夜 🐑 想請你花兩分鐘回答六題，怎麼想就怎麼寫，沒有標準答案：

1. 你打到第幾夜？用哪個難度（寧靜／起風／暴風）？
2. 哪一夜最卡？卡在什麼（錢不夠、羊被叼、來不及放、看不懂敵人）？
3. 第二章新夥伴裡，油燈、牧人杖、銀號、抱羊羔的牧人，哪些你真的會放？哪些放過一次就不放了，為什麼？
4. 有沒有哪個畫面或文字看不懂、或是點了沒反應？
5. 玩完之後，隔天有沒有自己再打開一次？沒有的話，是什麼讓你沒再開？
6. 一句話：如果第三章要加一個新東西，你希望是什麼？

遊戲網址：https://st00777.github.io/sheepfold-defense/

## 回饋對應的決定

- 第 2 題集中在同一夜 → 調那夜波表（跑 `node sim/simulate.js <夜> all 100 good`／`basic`）。
- 第 3 題「抱羊羔的牧人」沒人放 → 進 level-design.md「待重新評估」三個候選方向之一。
- 第 3 題「油燈」沒人放 → 不調（James 10/18 定調為隊伍取捨，非機制問題）。
- 第 5 題「隔天再開」比例 → 興趣作的成功標準（ADR：James 自己願意隔天再開；三人裡有人自己開第二次）。
- 第 6 題 → 對照 level-design.md「第三章以後（候選）」四條挑一條。
