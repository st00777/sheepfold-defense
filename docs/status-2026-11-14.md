## 3. 期 3 升級審查重跑（雇工、火盆、油燈）

11/1 內建審查對期 3 升級留下 6 條，當時只記了四個主題沒處理。這次對著目前 main 的程式重看一遍，每條都對過程式碼。

| 主題 | 結果 |
|---|---|
| 升級效果怎麼跟原本數值合併（`effOf`） | 沒找到問題。合併時會連名字、價錢一起蓋，但讀結果的五個地方只用光照、冷卻、濺射、逃跑四個欄位 |
| 雇工逃跑 | 沒找到問題。逃跑判定、獅吼、升級補血上限、續玩還原都跟規格一致；倒下的單位不能花糧升級 |
| 火盆上下排 | 沒找到問題。只算活著的火盆、穿過那一欄才點燃 |
| 模擬玩家升級順序 | 剩一條小的，見下 |

留下的兩條，都判定**不用動**：

1. 送卡夜（第 15 夜）把升級過的單位鏟回手上，升級不會跟著回來。實際碰不到：送卡夜糧永遠是 0（跑 120 秒驗過），根本升不了級。
2. 模擬器的「多排」打法在學會燈臺後，如果第一盞油燈沒放到中間那排，就不會再補中間。只影響模擬勝率，不影響真的遊戲；而且它本來就先試中間排。

結論：期 3 這批審查意見可以結案。

## 4. 動畫「待實機」本機預驗

用電腦 Chrome 模擬 360 寬的手機畫面先看一輪。電腦看不出來的照實留給真機。

| 項目 | 本機結果 | 還要不要真機 |
|---|---|---|
| 特效蓋住上一排血條 | 血條都看得清楚；煙往上延伸約半格。沒有刻意把敵人擺在煙正上方 | 順便看就好 |
| 頭目橫幅擋排 | **看到現象**：橫幅蓋住第 3 排中段與第 2 排下半，不透明約 1.2 秒。點得到格子，但那一秒看不到底下的敵人 | 要 James 判斷能不能接受 |
| 「再守這一夜」清晨疊入夜 | 量到兩層確實會同時出現（重開後 0.5 秒清晨還有六成五）。好不好看電腦判斷不了 | 要 |
| 2 倍速大鷹升降 | 讀程式確認：升降動畫不跟著加速，2 倍速時畫面比實際慢約 0.8 秒 | 要 |
| 結算頁底下棋盤照畫 | **看到現象**：結算頁每秒畫的次數跟對局中一模一樣，沒有省。10/23 審查當時決定不改；會不會燙要手機感覺 | 要 |
| 大字模式蠟燭火苗 | 沒問題。火苗頂離按鈕上緣還有 5 像素；大字只放大字、不改按鈕高度 | 不用 |
| 試煉金勾會不會被淡入吃掉 | 沒問題。選夜畫面幾乎全顯現後勾才開始畫 | 順便看就好 |

橫幅與結算頁兩條是「看到現象」不是「壞掉」，要不要改由 James 決定，這輪沒動程式。
