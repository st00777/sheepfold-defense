# 封面風格提示詞模板（2026-10-26）

封面 `img/cover.jpg` 的做法：CC 用遊戲裡的 Fluent 3D 圖示排一張草稿 → James 把草稿貼給 ChatGPT（網頁版，對話「插畫封面設計」，Instant 模式）→ 一次生成，未改稿。原圖 1730×909 在 James 的 `~/glc-work`。

之後要讓遊戲畫面往封面靠（底圖、前景、角色），**同一條路**：CC 排草稿、附封面當風格參考、提示詞用下面這段當開頭。

## 1. 封面原始提示詞（逐字）

> 請把這張圖畫成一張完整的插畫封面。這是聖經故事守塔小遊戲「羊圈守夜」的封面草稿，1200×630，臉書分享預覽用；草稿是用遊戲裡的 3D 圖示直接排出來的。請守住這幾條：1. 構圖不動：左邊羊圈柵欄裡的羊、牧人拿杖站在門口、牧羊犬和火盆在前；右邊狼、熊、獅子從暗處走過來；月亮在右上。好人左、壞人右。2. 風格對齊遊戲裡的圖示：圓潤的 3D 黏土感，不要寫實、不要嚇人，教會小朋友也會看；狼熊獅可以兇一點但要可愛。3. 光線：左邊是油燈和火盆的暖光，右邊是月光的冷藍，中間牧人站在兩種光的交界。4. 標題「羊圈守夜」保留在左上，繁體中文、金色、有分量；副標「聖經故事守塔小遊戲」小字放標題下面；畫面裡不要有其他文字。5. 把草稿裡生硬的地方補起來：柵欄畫成真的木頭、草地有深淺、角色腳下有影子，讓它們像站在同一塊地上而不是貼上去的。6. 輸出橫式 1200×630 的比例。

## 2. 可重用的風格段（每張圖都放在開頭）

> 風格對齊附圖（遊戲封面）：圓潤的 3D 黏土感，不要寫實、不要嚇人，教會小朋友也會看。夜景，暖光來自油燈與火盆（橘黃），冷光來自月亮（藍），兩種光要同時存在。畫面裡不要有任何文字。

## 4. 已知限制

- 10/18 研究：AI 生「同一角色的多張」會漂移，單張可靠。角色先試 5 張（牧人、羊、狗、狼、獅）並排進棋盤看，再決定開不開全部 43 張。
- ChatGPT 生圖沒有透明底，角色要用 `bible-art-assets` skill 的 rembg 去背。

## 5. 第一步做了什麼（2026-10-26，分支 `feat/cover-look`）

- **後景條** `img/backdrop.webp`（從原圖裁 x 830-1730、y 0-300，避開標題，10KB）：放在棋盤上方，高度＝寬度的 1/4，下緣 45% 壓一層深藍漸層接草地。
- **前景條** `img/foreground.webp`（原圖 y 784-909 整條，縮到 1200 寬，13KB）：放在棋盤下方、往上蓋 6px，草叢在棋盤「前面」。
- **放不放的規則**（index.html `fitBoard`）：直的手機寬度本來就被螢幕限住，兩條是白送的；寬螢幕高度不夠、加了兩條會讓棋盤縮超過 12% 時整個拿掉（`#stage.plain`），棋盤永遠不縮。
- **光照圖**（render.js `drawLight`）：整張棋盤相乘一層夜色，左邊羊圈那頭微暖 `#ddd3c3`、右邊敵人來的那頭月光冷藍 `#93a4d8`；火盆與油燈各有一個相加的暖圓（3.6／4.4 格）把那一帶的夜色洗掉。先畫進 RenderTexture 再相乘，暖圓之間不會疊黑；提示、飄字、黑暗層在它上面不受影響。天亮淡出、失守留著。
- 沒動：格子底色、單位圖示、`ground.webp`。
- 真機要看的：右半邊的冷藍會不會太暗看不清敵人（James 10/23 說過 .32 太暗）；前景條會不會擋到最下排的「修補」飄字。
